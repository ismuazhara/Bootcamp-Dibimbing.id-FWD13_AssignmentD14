Deskripsi : Sistem checkout produk sederhana dengan input harga, jumlah, dan member. harga dan jumlah bilangan positif. sub total dihitung dengan rumus harga x jumlah, member mendapat diskon 10%. total setelah diskon mendapatkan gartis ongkir jika total pembayaran minimal 250.000, jika lebih rendah mendapat ongkir 15000.

Cara menjalankan program : user menginput data harga dan jumlah, kemudian akan divalidasi dan dihitung sub total harga. setelah itu user akan diarahkan menuju bagian member untuk divalidasi agar mendapat diskon. sub total harga kemudian dikurangi dengan diskon. setelah pengurangan dengan diskon, kemudian biaya tadi dijumlahkan dengan ongkir. hasil output berupa total harga = subtotal - harga diskon + ongkir.

AI = penggunaan AI untuk membuat struktur dari javascript checkout.js
